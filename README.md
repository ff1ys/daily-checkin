# 每日打卡 · 学习 / 单词 / 喝水

一个手机端优先的日常打卡 App，单个文件夹、零依赖、无需登录，数据只存在你自己的浏览器里。

- **学习记录**：正计时 / 番茄钟，记录科目、内容和每一段的时长；支持手动补记
- **单词本**：随手记生词（单词、音标、释义、例句、标签），按「1 / 2 / 4 / 7 / 15 / 30 天」间隔重复复习，连续答对 5 次自动标为已掌握
- **喝水打卡**：一次一杯，可撤销，环形进度 + 连续达标 + 最近 7 天趋势
- **今日总览**：今日学习时长、喝水杯数、新增 / 待复习单词、连续打卡天数
- **统计与设置**：目标、杯量、科目、外观（跟随系统 / 浅色 / 深色）、数据导出导入

支持离线、可「添加到主屏幕」当 App 用。

## 怎么用

### 电脑上先看看

直接双击 `index.html` 就能打开（Chrome / Edge / Safari 都行）。

### 手机上用

**方式一：局域网访问（最快）**

1. 电脑和手机连同一个 Wi-Fi
2. 在电脑上进入这个文件夹，运行：

   ```bash
   node serve.mjs
   ```

3. 终端会打印类似 `http://192.168.1.23:4173/` 的地址，用手机浏览器打开
4. iPhone 用 Safari「分享 → 添加到主屏幕」；Android 用 Chrome 菜单「添加到主屏幕」

也可以直接双击 `启动.cmd`，它会帮你启动服务器并打开浏览器（没装 Node.js 时会改为直接打开 `index.html`）。

**方式二：部署到静态托管（长期使用推荐）**

把整个文件夹上传到 GitHub Pages、Vercel、Netlify 等任意静态托管，用手机打开网址后「添加到主屏幕」，即可获得可安装的 PWA 与离线缓存（需要 HTTPS）。

## 数据存在哪里

- 全部数据保存在浏览器的 `localStorage`，**不会上传任何服务器**
- 换浏览器、清理网站数据、换手机会丢失，建议偶尔在「我的 → 数据 → 导出数据」备份一份 JSON
- 换设备时在新设备上「导入数据」即可恢复

## 目录结构

```
study-checkin/
├─ index.html            页面骨架
├─ app.css               样式（含深色模式）
├─ store.js              数据层：localStorage、学习/喝水/单词、间隔重复
├─ app.js                界面与交互：五个页面、计时器、复习卡片、弹层
├─ manifest.webmanifest  PWA 配置
├─ sw.js                 离线缓存
├─ serve.mjs             本地静态服务器（零依赖）
├─ 启动.cmd              Windows 一键启动
├─ icons/                图标（由 tools/make_icons.py 生成）
└─ test/shot.mjs         无头 Chrome 截图 + 交互自测脚本
```

## 开发与自测

```bash
node serve.mjs          # http://localhost:4173
node test/shot.mjs      # 生成截图到 test/shots，并跑 16 项交互自测
```

`test/shot.mjs` 会用 390×844 的移动端视口打开页面，写入一份示例数据后逐页截图（浅色 / 深色），再验证喝水、加词、搜索、复习、计时、番茄钟、持久化等流程。

## 小提示

- 计时中切到别的页面不会中断，关掉页面再打开也会接着计时
- 番茄钟倒计时结束会自动把这段时间记入学习记录
- 单词的「待复习」按间隔重复自动安排，忘了的词第二天会再出现
